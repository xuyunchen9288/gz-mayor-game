# 🏛️ 广州市长模拟游戏

> 5年任期，30个双月周期，你是广州市的掌舵人。

## 🎮 游戏特色

- **🎯 真实模拟**：GDP、民心、上级印象、廉洁风险四大维度
- **📊 随机事件**：每年面临天灾、经贸、政策、城市事件，自行判断重要性
- **⏱️ 双月决策**：每个双月选择3项行动（50%/30%/20%精力权重）
- **🔒 隐藏指标**：民心和上级印象平时不可见，每年末揭晓
- **🏆 联网排行榜**：接入 JSONBin.io，跨设备同步成绩
- **⚖️ 秋后算账**：任上未被抓≠安全着陆，离任后仍可能被追责

## 🌐 在线游玩

**https://gz-mayor-game.vercel.app**

## 📱 分享方式

直接发送链接给朋友，无需下载，双击即玩（手机/电脑通用）。

## 🏆 排行榜配置

1. 打开 [jsonbin.io](https://jsonbin.io) 注册并创建 Collection
2. 复制 Bin ID
3. 在游戏设置中填入 Bin ID 即可联网对战

## 技术说明

纯 HTML 单文件游戏，无需任何依赖，跨平台兼容。
